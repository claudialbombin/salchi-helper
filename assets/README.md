<details>
<summary><b>🐕 How the dog is drawn</b></summary>

<br>

The dachshund is the same one that lives in the app: a handful of rounded rectangles and ellipses on a 140 × 104
canvas. Each scene reuses it and animates it with CSS keyframes:

| Animation | What moves |
| --- | --- |
| `tap` | The paws, typing in turns |
| `wag` | The tail |
| `blink` | The eyes, every few seconds |
| `steam` | The coffee |
| `run` + `leg` | The side-view dog trotting between devices |
| `float`, `stick`, `drop` | Sticky notes rising, being pinned or filed |

</details>
